# عنوانك للدعاية والإعلان | ANWANUK

متجر خدمات إعلانية تفاعلي باللغة العربية، مخصص لعنوانك للدعاية والإعلان في خميس مشيط — المملكة العربية السعودية.

**[معاينة مباشرة للموقع (خدمة خارجية)](https://raw.githack.com/ali200903ali-stack/sddss/anwanuk-website/index.html)**

## الميزات

- واجهة RTL متجاوبة مع الهاتف والكمبيوتر، بألوان الهوية البرتقالية والبيضاء والرمادية.
- معرض أعمال لخدمات الواجهات واللوحات والحروف البارزة.
- استديو مرئي لتحديد مقاس الواجهة، وارتفاع الحروف، والخامة، واللون والإضاءة.
- رفع صورة واجهة المحل محلياً في المتصفح للمعاينة، دون رفعها إلى خادم.
- سلة طلبات عرض أسعار، وتجهيز رسالة مفصلة للإرسال عبر واتساب.
- أقسام الخدمات والمشاريع والفيديوهات والتواصل وخريطة الموقع.

## التشغيل

افتح `index.html` مباشرة في المتصفح. الصفحة مستقلة ولا تحتاج إلى خادم أو npm.

## ملاحظات قبل الإطلاق التجاري

- لا توجد بوابة دفع أو قاعدة بيانات أو نظام حسابات؛ طلب عرض السعر يتم عبر رسالة واتساب.
- قد تتطلب صور المشاريع الخارجية الاتصال بالإنترنت وتظل خاضعة لتوفر المصدر.
- خدمة المعاينة أعلاه عبر raw.githack.com وليست GitHub Pages رسمية، ولا تعني تفعيل استضافة GitHub Pages على المستودع.
- لم تتم مزامنة فيديوهات تيك توك آلياً، بل أُضيف رابط الحساب.
- بيانات التواصل تُراجع من مالك النشاط قبل الاستخدام التجاري النهائي.
